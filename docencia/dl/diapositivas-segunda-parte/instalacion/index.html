Guía de instalación

Las cuatro piezas del Tema A en vuestro portátil: Claude Code, el Claude de escritorio (Cowork), opencode y Ollama con un modelo Qwen3 que cabe en un portátil normal. En Windows, macOS y Ubuntu. Todos los comandos están copiados de la documentación oficial el 15 de octubre de 2026; cada bloque lleva debajo la URL de donde salen.

Antes de empezar: qué toca esto en vuestro portátil

Nada de lo que hay aquí abajo toca el firmware (BIOS/UEFI), ni la tabla de particiones, ni el arranque. Los cuatro programas escriben en vuestra carpeta de usuario y añaden un comando al PATH.

CapaQué le pasa
Carpeta de usuario (~/.local, ~/.ollama, %USERPROFILE%)Aquí aterriza todo: los programas y los pesos del modelo
Sistema operativo (/usr/bin, Program Files)Sólo lo toca apt en Ubuntu, y pide la contraseña antes
Particiones y discoNo se tocan
Firmware · BIOS / UEFINo se toca. Ningún paso de esta guía entra ahí

Administrador. No hace falta en Windows ni en macOS. En Ubuntu lo pide apt, igual que para cualquier otro programa.

Espacio. Unos 4 GB para los programas, y entre 2,5 y 5,2 GB más por cada modelo de Ollama que os bajéis.

Desinstalar. Borrar una carpeta. Las órdenes exactas están al final.

La única excepción, y se esquiva. La pestaña Cowork del Claude de escritorio, en Ubuntu, levanta una máquina virtual y necesita virtualización por hardware activada en el firmware. Si os sale ese aviso, no entréis en la BIOS: usad Claude Code en la terminal, que ejecuta el mismo motor. En Windows y macOS el aviso no aparece.

1. Claude Code — el agente en la terminal

Es el que usamos en clase.

Windows (PowerShell). El prompt pone PS C:\>.

irm https://claude.ai/install.ps1 | iex

Windows (CMD). El prompt pone C:\>, sin el PS.

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS, Ubuntu y WSL.

curl -fsSL https://claude.ai/install.sh | bash

Comprobar. Abrid una terminal nueva (las ya abiertas no ven el PATH actualizado):

claude --version      # imprime algo como 2.1.211 (Claude Code)
claude doctor         # diagnóstico de la instalación, sin abrir sesión

Arrancar, dentro de la carpeta del proyecto:

cd ~/ventas
claude

Requisitos. macOS 13+, Windows 10 1809+, Ubuntu 20.04+ o Debian 10+; 4 GB de RAM; procesador x64 o ARM64.

Cuenta. Pide plan Pro, Max, Team, Enterprise o una cuenta de Console con crédito. El plan gratuito de claude.ai no incluye Claude Code.

Alternativas, si el script falla:

winget install Anthropic.ClaudeCode        # Windows
brew install --cask claude-code            # macOS
npm install -g @anthropic-ai/claude-code   # cualquiera, con Node.js 22+

Nunca con sudo npm install -g: la documentación lo desaconseja expresamente por los problemas de permisos que genera después.

Errores habituales.

Qué diceQué pasa
claude: command not foundCerrad la terminal y abrid otra
The token '&&' is not a valid statement separatorEstáis en PowerShell y habéis pegado el comando de CMD
'irm' is not recognized…Estáis en CMD y habéis pegado el de PowerShell

Fuente: code.claude.com/docs/en/setup

2. Claude de escritorio — Chat, Cowork y Code en la misma app

Una sola aplicación con tres pestañas: Chat para conversar, Cowork para encargos largos sobre carpetas, y Code para repositorios. Es la puerta por la que entrará la mayoría de vuestros compañeros de empresa.

Windows y macOS. Descarga directa desde claude.com/download: .exe en Windows, .dmg en macOS. Instalar, abrir, iniciar sesión. Descargad sólo desde ahí; las webs de «descarga gratuita» de terceros son una fuente habitual de instaladores con añadidos.

Ubuntu 22.04+ / Debian 12+ (beta). Cuatro pasos.

# 1. curl y gpg, si no los tenéis
sudo apt install curl gnupg

# 2. la clave de firma de Anthropic
sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc \
  https://downloads.claude.ai/claude-desktop/key.asc

#    comprobad que la huella es la de Anthropic:
#    31DDDE24DDFAB679F42D7BD2BAA929FF1A7ECACE
gpg --show-keys /usr/share/keyrings/claude-desktop-archive-keyring.asc

# 3. el repositorio
echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main" | sudo tee /etc/apt/sources.list.d/claude-desktop.list

# 4. instalar
sudo apt update && sudo apt install claude-desktop

Después, claude-desktop desde la terminal o Claude desde el lanzador de aplicaciones.

Cuenta. Se entra con la suscripción de claude.ai o con el SSO de la universidad. Cowork necesita plan de pago; la pestaña Chat, no.

Si apt dice Unable to locate package claude-desktop, falta el sudo apt update del paso 4. Si dice NO_PUBKEY BAA929FF1A7ECACE, la clave del paso 2 no se descargó bien.

Si la pestaña Cowork avisa de que necesita KVM, dejadla. No vamos a tocar el firmware por una pestaña: Claude Code en la terminal hace lo mismo.

Fuentes: claude.com/download · code.claude.com/docs/en/desktop-linux

3. Ollama + Qwen3 — el modelo que corre dentro del portátil

Instalar Ollama.

# macOS y Ubuntu
curl -fsSL https://ollama.com/install.sh | sh
# Windows: no necesita Administrador, instala en vuestra carpeta de usuario
winget install Ollama.Ollama

En macOS también vale bajar ollama.dmg de ollama.com/download y arrastrarlo a Aplicaciones. En Windows, OllamaSetup.exe de la misma página.

Bajar el modelo. Se baja una sola vez y luego funciona sin conexión:

ollama pull qwen3:8b     # 5,2 GB
ollama run qwen3:8b      # a probarlo; Ctrl-D para salir

Qué talla elegir. Regla práctica, no especificación:

ModeloDescargaRAM del portátil
qwen3:8b5,2 GB16 GB o más
qwen3:4b2,5 GB8 GB (y trae ventana de 256k)
qwen3:1.7b1,4 GBsi el portátil va muy justo

Si el portátil empieza a tirar de disco y cada respuesta tarda minutos, el modelo no cabe en RAM: bajad de talla. Sin GPU también funciona; en CPU va más lento, no deja de funcionar.

Dónde caen los pesos. ~/.ollama en macOS y Ubuntu, %HOMEPATH%\.ollama en Windows. Para ver lo que tenéis y recuperar disco:

ollama list
ollama rm qwen3:8b

Fuentes: docs.ollama.com/windows · ollama.com/library/qwen3

4. opencode — el agente libre, enchufado a Ollama

Instalar.

# macOS y Ubuntu
curl -fsSL https://opencode.ai/install | bash
# Windows (o, mejor, el comando de arriba dentro de WSL)
npm install -g opencode-ai

Decirle dónde está Ollama. Un fichero opencode.json en la raíz del proyecto:

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen3:8b": { "name": "Qwen3 8B" }
      }
    }
  }
}

Eso declara un proveedor llamado ollama, le dice que se habla con él con el protocolo de OpenAI, y que escucha en el puerto 11434 de vuestra propia máquina. Nada sale del portátil.

Usarlo.

opencode                                 # y dentro: /models
opencode --model ollama/qwen3:8b         # o eligiéndolo desde fuera
opencode models                          # qué modelos ve

Cambiando esas cinco líneas, el mismo opencode habla con Anthropic, con OpenAI o con el servidor de vuestra empresa. El agente no se entera.

Fuentes: opencode.ai/docs · opencode.ai/docs/providers · opencode.ai/docs/cli

Desinstalar

# Claude Code (instalación nativa), macOS / Ubuntu / WSL
rm -f ~/.local/bin/claude && rm -rf ~/.local/share/claude

# Claude Code en Windows (PowerShell)
Remove-Item "$env:USERPROFILE\.local\bin\claude.exe" -Force
Remove-Item "$env:USERPROFILE\.local\share\claude" -Recurse -Force

# Claude de escritorio en Ubuntu
sudo apt remove claude-desktop

# los pesos de Ollama
ollama rm qwen3:8b

Y, si queréis borrar también la configuración, ~/.claude y ~/.ollama.

Comprobación final

Las tres líneas que deben responder antes de la clase:

claude --version
opencode --version
ollama --version

Si alguna no responde, traedla sin resolver y la miramos en clase: el fallo de instalación de otro es la mejor demo que hay.
